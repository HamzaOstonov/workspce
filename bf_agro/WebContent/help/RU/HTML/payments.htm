Платежи

 Наверх  Назад  Вперёд

Для открытия модуля платежей нужно воспользоваться пунктом меню «Модули \ Коммунальные платежи \ Платежи» (см. Рисунок 1).

 

 

Рисунок 1

 

При выборе указанного пункта меню открывается карточка для регистрации нового платежа (см. Рисунок 3).

В модуле платежей можно зарегистрировать новый платёж, просмотреть список зарегистрированных платежей  (см. Рисунок 2), просмотреть карточку любого зарегистрированного платежа  (см. Рисунок 4).

 

Рисунок 2

 

Для отображения формы регистрации нового платежа необходимо нажать кнопку , расположенную в панели управления над списком.

Форма содержит следующие поля (см. Рисунок 4):

Рисунок 3

 

•Категория – поле заполняется выбором нужной категории платежа из выпадающего списка. Обязательно для заполнения.

•Область – вспомогательное поле. Используется при необходимости фильтрации списка поставщиков по областям. Необязательно для заполнения.

•Район – вспомогательное поле. Используется при необходимости фильтрации списка поставщиков по районам. Необязательно для заполнения.

•Поставщик – поставщик оплачиваемой услуги, получатель средств. Поле заполняется выбором нужной записи из выпадающего списка. Обязательно для заполнения.

•Сервис – оплачиваемая услуга. Поле заполняется выбором нужной записи из выпадающего списка. Обязательно для заполнения.

•Счёт – счёт плательщика в биллинге поставщика. Поле заполняется выбором нужной записи из выпадающего списка. Обязательно для заполнения.

•Способ оплаты – в зависимости от выбранного способа оплаты, после подтверждения платежа, будут формироваться те или иные проводки (см. настройку проводок в модуле: «Modullar \ Kommunal to’lovlar \ Kom. To'lovlarni sozlash»). Обязательно для заполнения.

•Сумма – сумма платежа. Указывается в сумах в формате “999999.99” Обязательно для заполнения.

 

Для активации платежа необходимо нажать кнопку , расположенную в панели управления внизу формы.

Для отказа от платежа необходимо нажать кнопку , расположенную в панели управления внизу формы.
