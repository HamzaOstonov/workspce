Поставщики

 Наверх  Назад  Вперёд

Модуль поставщиков доступен из пункта меню «Модули \ Коммунальные платежи \ Поставщики»  (см. Рисунок 1).

 Рисунок 1

 

Работа в модуле начинается со списка поставщиков (см. Рисунок 2).

 Рисунок 2

 

Первоначально список поставщиков формируется на основании данных, переданных из Центробанка. В дальнейшем Банк может самостоятельно регистрировать тех поставщиков, с которыми есть договорные отношения.

Для отображения формы регистрации нового постащика необходимо нажать кнопку , расположенную в панели управления над списком. Для открытия формы редактирования поставщика из списка необходимо нажать кнопку .

 

Форма содержит следующие поля (см. Рисунок 3):

 Рисунок 3

 

•Филиал – МФО банка, обслуживающего поставщика. Обязательно для заполнения.

•Счёт – расчётный счёт поставщика. Этот счёт будет автоматически использоваться Системой при регистрации платежей для данного поставщика. Обязательно для заполнения.

•Наименование – наименование поставщика. Обязательно для заполнения.

•ИНН – ИНН поставщика.

•Область – область, к которой относится поставщик / регистрируемый филиал поставщика. Поле в дальнейшем может быть использования для фильтра при поиске поставщика. Например, при регистрации платежа.

•Район – Район, к которому относится поставщик / регистрируемый филиал поставщика. Поле в дальнейшем может быть использования для фильтра при поиске поставщика. Например, при регистрации платежа.

•Номер договора – номер договора с поставщиком.

•Дата договора – дата договора с поставщиком.

•Назначение платежа – назначение платежа по умолчанию для текущего поставщика. Поле заполняется с клавиатуры. Внесённый текст   в дальнейшем может быть использован при настройке автоматических проводок.

•Бюджетный ИНН – бюджетный ИНН поставщика.  Поле заполняется с клавиатуры.

•Бюджетный счёт – бюджетный счёт  поставщика. Поле заполняется с клавиатуры.

•Является Бюдж. – признак того, что поставщик - бюджетная  организация.

•Код назначения платежа – код назначения платежа из банковского справочника. Поле заполняется с клавиатуры.

•Категория – категория платежей для поставщика. Поле заполняется выбором из справочника.

 

Для сохранения данных в форме нужно нажать кнопку .

Для отмены внесённых изменений нужно нажать кнопку .
